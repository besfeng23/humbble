## 2. Current Route Reachability Checklist (Actual Files under `app/`)

Inspection of the current repository (`app/`) reveals 12 actual route/layout files:

- [x] `app/_layout.tsx` — **Root Stack Layout (Reachable):** Wraps the app in `<AuthProvider>` and registers five `Stack.Screen` entries: `(tabs)`, `auth/signin`, `auth/signup`, `charscreenf`, and `+not-found`.
- [x] `app/+not-found.tsx` — **Fallback 404 Screen (Reachable):** Standard Expo Router unmatched-route screen with a link back to `/`.
- [x] `app/auth/signin.tsx` — **Sign-In Screen (Reachable, Public):** Reached via `<Redirect href="/auth/signin" />` when `session` is null in `app/(tabs)/_layout.tsx` or `app/charscreenf.tsx`, or via link from `app/auth/signup.tsx`. Navigates to `/(tabs)/people` on success.
- [x] `app/auth/signup.tsx` — **Sign-Up Screen (Reachable, Public):** Reached from `app/auth/signin.tsx`. Uses `supabase.auth.signUp` (currently missing the 18+ DOB gate and `consent_records` capture required by `SCR-04`).
- [x] `app/(tabs)/_layout.tsx` — **Bottom Tab Layout (Reachable, Auth-Guarded):** Checks `useAuth()`; renders a loading spinner while `loading` is true and redirects unauthenticated users (`!session`) to `/auth/signin`. Sets `initialRouteName="people"` and defines 5 tabs (`profile`, `discover`, `people`, `(chats)`, `index`).
- [x] `app/(tabs)/people.tsx` — **Swipe Deck ("People" Tab, Initial Tab Route):** Despite the filename `people.tsx`, this file actually implements the interactive card swipe deck (`PanResponder` horizontal swipe cards backed by mock `DB/userDB.tsx`). In target v1.1 architecture, the discovery feed consolidates into `SCR-11` (`app/(tabs)/discover.tsx`) while `people.tsx` is replaced by `SCR-14` (`app/(tabs)/likes.tsx`).
- [x] `app/(tabs)/index.tsx` — **"liked You" Tab (Reachable via Tab Bar):** Registered in `app/(tabs)/_layout.tsx` with `title: "liked You"` (heart icon). Renders static "See who likes you" marketing copy, category pills, and a static "Upgrade to Humbble Premium" button. Maps to target `SCR-14` (`app/(tabs)/likes.tsx`) and `SCR-11` consolidation.
- [x] `app/(tabs)/discover.tsx` — **Static Categorized Lists ("Discover" Tab, Reachable via Tab Bar):** Renders horizontal `FlatList` rails ("Recommend For You", "Same interest", "Similar Hobby") populated from client-side mock `DB/userDB.tsx`. Maps to target `SCR-11` (`app/(tabs)/discover.tsx`).
- [x] `app/(tabs)/profile.tsx` — **User Profile ("Profile" Tab, Reachable via Tab Bar):** Displays hardcoded user avatar ("Suzzane, 23"), static "Get Spotlight" / "Humbble premium" upsell cards, and a "Sign Out" button calling `supabase.auth.signOut()`. Maps to target `SCR-17` (`app/(tabs)/profile/index.tsx`).
- [x] `app/(tabs)/(chats)/_layout.tsx` — **Nested Chat Stack Layout (Reachable via "Chats" Tab, Case-Mismatch Quirk):** Declares `<Stack.Screen name="index" />` and `<Stack.Screen name="chatscreen" />` (all lowercase), whereas the actual file on disk is `app/(tabs)/(chats)/chatScreen.tsx` (camelCase `S`). On case-sensitive Linux/Web bundlers and route resolution, this casing mismatch (`chatscreen` vs `chatScreen.tsx`) is a routing defect.
- [x] `app/(tabs)/(chats)/index.tsx` — **Chats Inbox Screen (Reachable via "Chats" Tab):** Renders a static "Your matches" header and Spotlight promo. Tapping "Your matches" executes `router.push("/charscreenf")` (navigating to root-level `app/charscreenf.tsx` instead of `app/(tabs)/(chats)/chatScreen.tsx`). Maps to target `SCR-15`.
- [x] `app/(tabs)/(chats)/chatScreen.tsx` — **Chat Conversation UI Shell (Orphaned / Unlinked in UI):** Contains a static UI shell (`<Text>chatScreen</Text>`). Not linked from `app/(tabs)/(chats)/index.tsx` (which links to `/charscreenf` instead) and mismatched against `name="chatscreen"` in `app/(tabs)/(chats)/_layout.tsx`. Maps to target `SCR-16` (`app/(tabs)/(chats)/[conversationId].tsx`).
- [x] `app/charscreenf.tsx` — **Root Test Chat Screen (Reachable, Auth-Guarded, Linked from Chats):** Registered in `app/_layout.tsx` (`name="charscreenf"`), explicitly auth-guarded via `useAuth()` (`if (!session) return <Redirect href="/auth/signin" />`), and linked directly from `app/(tabs)/(chats)/index.tsx` via `router.push("/charscreenf")`. Renders placeholder text `charscreen 234 root`.
